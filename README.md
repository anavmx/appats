# 🚀 Carreira+ | Plataforma Inteligente de Empregabilidade

### Sua próxima oportunidade começa com o currículo certo!

O **Carreira+** é uma aplicação web que estou desenvolvendo com o objetivo de facilitar a busca por oportunidades de emprego e ajudar candidatos a se prepararem melhor para os processos seletivos.

A ideia é utilizar tecnologia e inteligência artificial para aproximar candidatos de vagas compatíveis com seus perfis profissionais, além de auxiliar na criação de currículos personalizados e otimizados para sistemas ATS (*Applicant Tracking Systems*).

## 💡 Sobre o projeto

O Carreira+ funciona como um assistente de carreira, reunindo em uma única plataforma recursos para busca de empregos, análise de compatibilidade profissional e criação de currículos personalizados.

A proposta é que o usuário cadastre suas informações profissionais uma única vez e consiga utilizar esses dados para encontrar oportunidades e gerar diferentes versões do currículo de acordo com cada vaga.

## ✨ Funcionalidades

### 👤 1. Perfil profissional
- Cadastro de informações pessoais e profissionais.
- Inclusão de experiências profissionais.
- Cadastro de formação acadêmica.
- Registro de cursos, certificações e idiomas.
- Cadastro de habilidades técnicas e comportamentais.
- Inclusão de LinkedIn, GitHub e portfólio.
